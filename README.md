## How it works

Everything is generated by a handful of Python scripts and kept fresh by a
GitHub Actions cron. GitHub strips `<script>` from READMEs, so all the motion
lives inside self-contained SVGs (SMIL + CSS keyframes), which GitHub *does*
render and animate via `<img>`.

- `scripts/prep_photo.py` — background removal (rembg) + local contrast
  (OpenCV CLAHE) + white composite. **Run locally when you change your photo.**
  Outputs `source-prepped.pgm`.
- `scripts/make_ascii_svg.py` — turns the PGM into `ascii.svg`: a 100×53
  monochrome portrait whose rows type in top-to-bottom, inside a terminal
  window. Pure stdlib.
- `scripts/make_wordmark_svg.py` — renders `wordmark.svg`: the text extruded
  into a 3D slab, rasterized to ASCII characters, wiping in left-to-right
  then rocking on its vertical axis (a pre-rendered SMIL flipbook). Pure
  Python; auto-upgrades to a bold TTF render when numpy + Pillow are
  installed.
- `scripts/fetch_contributions.py` — scrapes
  `https://github.com/users/<you>/contributions` (no token) →
  `data/contributions.json`. Pure stdlib.
- `scripts/render_heatmap_svg.py` — renders `contrib-heatmap.svg`: the 53-week
  calendar as rounded boxes revealing diagonally, with month/weekday labels,
  a Less→More legend and a live stats footer. Pure stdlib.
- `.github/workflows/update-profile-art.yml` — cron re-scrapes + re-renders
  the heatmap daily and commits it.

## Setup

1. **This repo must be named exactly your GitHub username** and be public —
   its `README.md` renders at the top of your profile.
2. Set your details once in `scripts/config.py`: `USERNAME`, `PROMPT`,
   `PROFILE_NAME`.
3. Local run (no dependencies):
   ```bash
   python scripts/fetch_contributions.py
   python scripts/render_heatmap_svg.py
   python scripts/make_wordmark_svg.py --mode rock
   python scripts/make_ascii_svg.py            # needs source-prepped.pgm
   ```
4. **Your photo (optional but recommended):**
   ```bash
   python -m venv .venv && source .venv/bin/activate
   pip install -r scripts/requirements.txt
   python scripts/prep_photo.py my-photo.jpg
   python scripts/make_ascii_svg.py
   python scripts/make_wordmark_svg.py --mode rock   # crisp TTF letters
   ```
   Without the photo, `ascii.svg` renders a placeholder pattern — swap in
   your own `source-prepped.pgm` (or PNG) whenever you like.
5. Push. Trigger the workflow once from the **Actions** tab
   (`workflow_dispatch`) to confirm it commits a fresh SVG.

## Notes / gotchas

- Inline `style="margin-top:…"` does nothing in READMEs — use `<br>`.
- `<h1>`/`<h2>` draw a full-width underline; use `<h3>` for headers without
  the rule.
- Table widths are chosen so the heatmap (860) equals portrait + wordmark
  (370 + 490) — edges line up.

and [wordmark write-up](https://www.avivashishta.com/blog/3d-ascii-wordmark-svg-github-readme).
